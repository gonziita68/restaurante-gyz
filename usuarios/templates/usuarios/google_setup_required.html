Configuración Requerida

Para usar el login con Google, necesitas configurar las credenciales de OAuth

Nota: Esta es una página temporal. Una vez configures Google OAuth, el login social funcionará automáticamente.

📋 Pasos para Configurar Google OAuth:

  1. Crear proyecto en Google Cloud Console: Ve a Google Cloud Console
  2. Habilitar API de Google+: En "APIs y servicios" > "Biblioteca"
  3. Crear credenciales OAuth 2.0: En "APIs y servicios" > "Credenciales"
  4. Configurar URIs autorizados:
    • URI de origen: http://localhost:8000
    • URI de redirección: http://localhost:8000/accounts/google/login/callback/
  5. Configurar en Django Admin: Ve a Django Admin y crea una "Social Application"
